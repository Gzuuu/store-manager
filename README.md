# 🛒 Store Manager

## ✨ Descrição Breve  
No projeto **Store Manager**, desenvolvi minha **primeira API** utilizando a arquitetura **Model Service Controller (MSC)**. A aplicação é um sistema de gerenciamento de vendas no formato **dropshipping**, onde é possível **criar, visualizar, deletar e atualizar produtos e vendas**. A API foi construída no formato **RESTful**, com **MySQL** como banco de dados.

## 🚀 Como Rodar o Projeto  
1. Clone o repositório:  
   ```bash
   git clone https://github.com/Gzuuu/store-manager.git
   ```  
2. Acesse a pasta do projeto:  
   ```bash
   cd store-manager
   ```  
3. Instale as dependências:  
   ```bash
   npm install
   ```  
4. Inicie o servidor:  
   ```bash
   npm start
   ```  

## 🛠️ Tecnologias Utilizadas  
- **Node.js**  
- **Express**  
- **MySQL**  
- **Arquitetura Model Service Controller (MSC)**  

## ⚙️ Funcionalidades  
- 📦 Gerenciamento de **produtos** (criação, visualização, atualização e deleção).  
- 🏷️ Gerenciamento de **vendas** (criação, visualização, atualização e deleção).  
- 🔄 API **RESTful** para comunicação com o front-end.  

## 📚 Principais Aprendizados  
- Criação de **APIs RESTful** utilizando o **Node.js**.  
- Aplicação da arquitetura **Model Service Controller (MSC)** para organização de código.  
- Integração da aplicação com **MySQL** para persistência de dados.  
- Desenvolvimento de uma **API de gerenciamento de vendas**.
